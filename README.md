# BETONFIRES BOT

Личный исследовательский Telegram-бот для **CS2 и Dota 2**: [@BETONFIRES_BOT](https://t.me/BETONFIRES_BOT).

Код подготовлен к размещению. **Программа пока не запущена в облаке, источники матчей и коэффициентов не подключены.** Локально прошли 37 технических тестов; живые подключения не проверены. Режим — виртуальный банк, прибыльность модели не подтверждена.

## Запуск с iPhone

Репозиторий уже содержит программу и `render.yaml`. Файлы вручную загружать не нужно.

**Размещение платное:** один Render Background Worker `0.5c-512mb` и постоянный диск 1 GB. Прежде чем подтверждать создание ресурсов, проверь итоговую стоимость на экране Render. Этот репозиторий не оплачивает и не запускает хостинг автоматически. Источник букмекерских коэффициентов может потребовать отдельного тарифа.

[Открыть настройку запуска в Render](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Fcloudise%2Fbetonfires-bot)

1. Войди в Render через браузер. На экране проверки ресурсов должны быть один новый worker и один диск.
2. В защищённое поле `TELEGRAM_BOT_TOKEN` введи токен своего бота из BotFather. Ключи не добавляются в GitHub и не отправляются в чат ChatGPT.
3. Подтверждай развёртывание только после проверки стоимости. После запуска найди `PAIRING_CODE` в Environment worker.
4. Отправь **своему боту** `/pair КОД`, заменив `КОД` значением из Environment. После привязки бот отвечает только тебе. Числовой Telegram ID вводить не нужно.
5. Отправь `/status` и `/help`. Затем подключи источники данных по [инструкции](IPHONE_SETUP.md).

После размещения открытый Safari и компьютер не требуются. До подключения источников бот сообщает о режиме настройки и не показывает придуманные матчи.

## Что подготовлено

- Расписание и результаты CS2/Dota 2 через PandaScore после добавления ключа.
- Необязательный импорт линии BetBoom через сторонний API-SPORT, выключенный по умолчанию.
- Экспериментальная Elo-модель отдельно по игре и BO-формату, фильтры недостаточной истории и устаревших данных.
- Виртуальный банк, журнал с расчётом результатов, P&L, ROI, просадка и сводка по времени Москвы.
- Условный калькулятор экспресса с явным допущением независимости.
- Привязка владельца по случайному коду и постоянное хранение SQLite-базы на диске worker.

**Реальные рекомендации остаются 0%.** Виртуальные 0.25% на сделку и лимиты 1% — параметры эксперимента, а не безопасная стратегия реальных ставок. Автоматических реальных ставок и доступа к балансу БК нет.

Полная [техническая инструкция](TECHNICAL.md), [настройка с iPhone](IPHONE_SETUP.md).

## Проверки

Python 3.11+, без сторонних Python-пакетов:

```bash
python3 -m unittest discover -s tests -v
python3 -m esports_bot demo
```

Все команды, коэффициенты и результаты в демо вымышленные. Технические проверки не подтверждают качество прогнозов.

Публичный код содержит только пустой `.env.example` и тестовые значения. Настоящие токены хранятся в Environment хостинга. Подробности выбранных ресурсов: [Blueprint](https://render.com/docs/blueprint-spec), [worker](https://render.com/docs/background-workers), [диск](https://render.com/docs/disks), [тарифы](https://render.com/pricing).
