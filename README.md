# BETONFIRES BOT — бесплатный запуск

Личный исследовательский Telegram-бот для **CS2 и Dota 2**: [@BETONFIRES_BOT](https://t.me/BETONFIRES_BOT).

Новый вариант использует **Cloudflare Workers Free + D1**. Постоянный сервер и платный диск не нужны: Telegram отправляет сообщение на webhook, а виртуальный журнал хранится в D1. Фоновое обновление разбито на небольшие задачи.

**Статус:** код подготовлен и проверен локально. Cloudflare в аккаунте владельца ещё не развёрнут, Telegram webhook и настоящие источники не проверены. Модель экспериментальная, прибыльность не подтверждена.

## Запуск с iPhone

[Настроить бесплатный запуск в Cloudflare](https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2Fcloudise%2Fbetonfires-bot)

1. Открой ссылку в Safari, войди или зарегистрируйся в Cloudflare. Используй **Workers Free**. Нужны только Worker и D1; платные функции и Render не требуются.
2. При настройке шаблона в поле секрета `TELEGRAM_BOT_TOKEN` введи токен своего бота из BotFather. Ключи не добавляются в GitHub и не отправляются в ChatGPT.
3. После успешного развёртывания открой выданный адрес Worker вида `https://…workers.dev`. На странице подключения подтверди настройку тем же токеном. Он передаётся только твоему Worker по HTTPS, не сохраняется в браузере и не попадает в базу.
4. Нажми **«Открыть моего бота»**, затем **Start** в Telegram. Одноразовая ссылка привяжет бота к твоему аккаунту. Срок ссылки — час.
5. В боте отправь `/status` и `/help`. Для настоящих матчей затем добавь бесплатный ключ `PANDASCORE_TOKEN` в секреты Worker. Полная [инструкция с iPhone](IPHONE_SETUP.md).

Без подключённого источника бот не показывает придуманные матчи. После настройки открытый Safari и компьютер не нужны. Если Cloudflare предлагает платный план, не выбирай его для этого проекта. Важно оставаться в бесплатных квотах: превышение может остановить обработку, а не дать бесконечный бесплатный сервер.

## Возможности бесплатного режима

- Расписание и результаты CS2/Dota 2 через бесплатные fixtures-endpoints PandaScore после добавления собственного ключа.
- Коэффициенты BetBoom **вручную**: `/odds ID КФ_A КФ_B`; автоматический платный API-SPORT здесь не используется.
- Экспериментальный Elo отдельно по игре и BO1/BO3/BO5. При недостатке или устаревании данных — пропуск.
- Виртуальный банк, атомарные ограничения расходов, журнал, расчёт результатов, P&L, ROI и просадка.
- Сводки по Москве и условный калькулятор экспресса; подходящих событий может не быть.
- Владелец по одноразовой ссылке, проверка подписи webhook, защита от повторной обработки Telegram-сообщений.

**Реальные рекомендации — 0%.** Виртуальные 0.25% на сделку и лимиты 1% — параметры эксперимента, а не безопасная стратегия реальных ставок.

## Ограничения

У Workers Free лимит CPU — 10 мс на вызов. Поэтому одна фоновая задача обрабатывает одну небольшую порцию; модель использует до **500 последних подходящих серий на игру**, кэшируется и не пересчитывается для каждого сообщения. Первичная история заполняется постепенно; глубина дополнительных страниц ограничена пятью. Полный цикл фоновых задач — примерно 12 минут, возможны задержки. В бесплатном Worker тяжёлый backtest не запускается. Python-реализация для отдельного анализа истории сохранена в репозитории.

Локальные проверки используют SQLite-адаптер D1 и вымышленные ответы API. Это проверка кода, а не работа на настоящей инфраструктуре Cloudflare. Холодный старт, фактический CPU на тарифе Free, квоты API и доступность конкретных матчей нужно проверить после развёртывания. Если лимиты будут превышены, требуется оптимизация, а не автоматическое подключение оплаты.

Нет модели актуальных составов, замен, veto, карт, патча и драфта. Положительный расчётный EV непроверенной модели не доказывает прибыльности. Два похожих названия команд или неизвестный формат не дают оснований придумывать вероятность.

## Проверки

Для бесплатного Worker, Node.js 22.13+:

```bash
npm test
```

Для сохранённой Python-версии:

```bash
python3 -m unittest discover -s tests -v
python3 -m esports_bot demo
```

Все матчи в демо вымышленные. Количество тестов не подтверждает точность прогнозов. Python-настройки находятся в `.env.python.example`; актуальные секреты Worker описаны в `.dev.vars.example`.

Документация: [Workers Free и лимиты](https://developers.cloudflare.com/workers/platform/limits/), [D1 Free](https://developers.cloudflare.com/d1/platform/pricing/), [развёртывание шаблона](https://developers.cloudflare.com/workers/platform/deploy-buttons/), [автоматическое создание D1](https://developers.cloudflare.com/changelog/post/2025-10-24-automatic-resource-provisioning/), [PandaScore plans](https://developers.pandascore.co/docs/plan-reference).

`render.yaml` удалён из актуального пути, чтобы случайно не запустить платный worker. Уже созданные вручную ресурсы Render это изменение не удаляет: если они есть, их нужно проверить в своём аккаунте отдельно.
