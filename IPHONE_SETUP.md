# Бесплатный запуск @BETONFIRES_BOT с iPhone

Актуальный путь: **Cloudflare Workers Free + D1**. Постоянный Python-сервер, Render и платный диск не нужны. Программа подготовлена и проверена локально, но в твоём аккаунте Cloudflare ещё не развёрнута.

## 1. Создать бесплатный Worker

Открой в Safari [настройку шаблона Cloudflare](https://deploy.workers.cloudflare.com/?url=https%3A%2F%2Fgithub.com%2Fcloudise%2Fbetonfires-bot).

Войди или зарегистрируйся в Cloudflare. Выбирай **Workers Free**, без перехода на Workers Paid. Нужны только Worker и база D1. Домен, платный сервер, R2, Workers AI и другие платные продукты для этой версии не требуются.

Шаблон может предложить создать копию GitHub-репозитория. Исходный `cloudise/betonfires-bot` уже существует, поэтому для копии выбери другое свободное имя, например `betonfires-bot-free`. Дальнейшие изменения развёрнутого приложения должны попадать именно в выбранную копию. Сохрани её ссылку.

Токен из официального [@BotFather](https://t.me/BotFather) введи в поле секрета `TELEGRAM_BOT_TOKEN`. Это токен твоего @BETONFIRES_BOT. Значения секретов в исходники GitHub и в ChatGPT не отправляют.

Приложение использует `wrangler.json`. Нужна привязка D1 с именем **DB**; шаблон создаёт её автоматически. Идентификатор базы вручную придумывать не нужно. Команда сборки: `npm run build`; развёртывания: `npm run deploy`. Они уже указаны в проекте.

Если используешь подключение существующего репозитория через Workers & Pages → Create application → Import Git repository, выбирай `cloudise/betonfires-bot`, корневую папку репозитория и имя Worker **betonfires-bot**, совпадающее с конфигурацией.

Этот мобильный сценарий и фактическое создание ресурсов ещё не проверены на твоём аккаунте. Если сервис предлагает платный план или требует платные дополнительные ресурсы, не подключай их для этого проекта.

## 2. Подключить Telegram

После успешного развёртывания Cloudflare покажет адрес вида `https://…workers.dev`. Это **адрес твоего Worker**, не ссылка на GitHub и не адрес Telegram.

Открой его. На странице подключения:
1. Введи тот же токен BotFather для подтверждения настройки.
2. Нажми «Подключить Telegram».
3. Нажми «Открыть моего бота».
4. В Telegram нажми **Start** в течение часа.

Токен на странице отправляется только твоему Worker по HTTPS для проверки с его секретом. Он не сохраняется в браузере или базе и не передаётся сторонним скриптам. Проверяй, что адрес совпадает с адресом, выданным в твоём аккаунте Cloudflare. В GitHub/чат токен не вставляется.

Одноразовая ссылка привяжет владельца. После этого чужие сообщения игнорируются. Числовой Telegram ID знать не нужно. Ссылка действует час; после привязки повторно использовать её для другого владельца нельзя.

Если у бота уже есть другой webhook, страница сообщит об этом и попросит отдельно подтвердить замену. Это отключит прежний адрес получения сообщений. Очередь старых сообщений автоматически не удаляется. Одновременно запускать Python polling и webhook нельзя.

Теперь отправь боту `/status` и `/help`.

## 3. Подключить реальные матчи бесплатно

В аккаунте [PandaScore](https://app.pandascore.co/) получи ключ плана Free / Fixtures и проверь доступ к расписанию и результатам CS2 и Dota 2. Этому коду не нужны платные endpoints подробной статистики.

В настройках своего Worker: **Settings → Variables and Secrets**, добавь **секрет** `PANDASCORE_TOKEN` и сохрани с развёртыванием новой версии.

До добавления ключа бот не загружает реальные матчи и не выдумывает расписание. После добавления фоновые задачи запускаются раз в минуту, но одна задача обрабатывает только одну небольшую порцию. Полный цикл — примерно 12 минут. История заполняется постепенно, поэтому сначала подходящих прогнозов может не быть.

Модель использует до 500 последних подходящих серий на игру. Минимум — 10 серий того же BO на каждую команду и недавняя история за 45 дней. BO2 и неизвестные форматы пропускаются.

Проверь `/matches`, затем `/analyze ID` и `/model`.

## 4. Коэффициенты BetBoom

**Автоматический платный API-SPORT в бесплатном Worker не используется.** Постоянный бесплатный источник именно линии BetBoom ещё не подтверждён.

Для проверки первой версии открой нужный матч в приложении BetBoom и введи оба коэффициента победителя **всей серии** в порядке A/B из `/analyze`:

```
/odds ID КФ_A КФ_B
```

Например, синтаксис `/odds csgo:123 1.90 2.05`. ID здесь пример; настоящий ID берётся из `/matches`. Нужны два исхода без ничьей, не отдельная карта, фора или тотал. Линия годна 10 минут после ручного ввода; пользователь сам проверяет, что котировка актуальна.

Реальный баланс вводится только для справки:
```
/balance 10000
```

Виртуальный банк создаётся один раз:
```
/paperbank 10000
```

Виртуальную сделку можно записать только при разрешении текущего эксперимента:
```
/paper ID A
```

Виртуально используется 0.25% банка на сделку, максимум 1% открытых и 1% размещённых за 24 часа. Это параметры теста, а не безопасные реальные ставки. Реальная рекомендация остаётся **0%**.

## 5. Ежедневное использование

- `/today` — сводка, виртуальные кандидаты и условный экспресс, если есть подходящая пара.
- `/subscribe 10:00` — сводка на 10:00 Москвы с возможной задержкой фонового запуска.
- `/journal` и `/bank` — результаты виртуальных записей.
- Открытый Safari не нужен: Telegram вызывает Worker при сообщении, Cron обновляет кэш.
- Журнал, владелец и настройки хранятся в D1, а не на диске временного процесса. Удаление базы удаляет эти данные.
- При замене Worker сохрани исходную привязку **DB**. Не подключай пустую новую базу к уже работающему журналу.
- Не запускай старый платный Render-проект для этого варианта. Если ты ранее создал ресурсы Render вручную, этот репозиторий не отменяет их оплату — проверь их отдельно в своём аккаунте.

## Ограничения бесплатного тарифа и проверки

Workers Free ограничивает обработку 10 мс CPU на вызов. D1 тоже имеет бесплатные квоты чтения, записи и хранения. При превышении квот обработка может останавливаться; автоматическое подключение оплаты код не делает.

Состояние смотри в Cloudflare **Metrics / Errors**, особенно `Exceeded CPU Time Limits` / 1102. Переход на оплату не является решением по умолчанию: сначала уменьшают объём порций и проверяют источник. Работа именно на твоём тарифе, холодные старты, настоящие API и доставка Telegram ещё требуют проверки после развёртывания.

Повторные webhook-сообщения не повторяют виртуальную сделку. Если процесс упадёт после записи сделки, но до ответа, ответ может потеряться; проверь `/journal` перед повтором. Сводки тоже отправляются не более одного раза за дату; при сбое доставки её можно запросить через `/today`.

Правило виртуального расчёта: отмена/технический результат/ничья/неподдерживаемый завершённый формат — возврат, нормальный результат — расчёт по исходной команде и сохранённому коэффициенту. Это правила эксперимента, не полная копия регламента BetBoom. Исправления результатов после расчёта автоматически журнал не переписывают.

Модель не учитывает актуальные составы, замены, veto, карты, патч или драфт. Технические тесты и положительный EV по некалиброванному Elo не доказывают прибыльности. Экспресс — условный калькулятор с недоказанной независимостью событий.
